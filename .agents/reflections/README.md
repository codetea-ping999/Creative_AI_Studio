# Reflections

Reflections are evidence-backed candidate lessons, not canonical truth.

Lifecycle:

```text
inbox -> validated -> promoted
      -> rejected
      -> archive
```

- `inbox/`: unvalidated candidate lessons.
- `validated/`: supported lessons not yet incorporated into canonical behavior.
- `promoted/`: provenance for lessons incorporated into memory and/or skills.
- `rejected/`: candidates that failed evidence, scope, contradiction, or usefulness checks.
- `archive/`: historical material no longer active in the promotion workflow.

A reflection cannot promote itself. Promotion requires durable evidence, independent validation, contradiction checks, and explicit scope/freshness as defined by the governing ADR.
