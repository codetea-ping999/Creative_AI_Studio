# 画像プリセット（Portrait / Anime / Cinematic）

画像の「つくる」画面には、本番用のプリセットが 3 つあります。定義は
[`apps/web/src/lib/imagePresets.ts`](../apps/web/src/lib/imagePresets.ts) の
`productionImagePresets` だけにあり、ここが唯一の正本です。

| プリセット | 想定する用途 | モデル | サイズ | ステップ | CFG |
|---|---|---|---|---|---|
| ポートレート | 1 人の人物、自然な肌、浅い被写界深度、縦 4:5 | `sdxl` | 832×1024 | 30 | 6.5 |
| アニメ | 線画とセル塗りのアニメ調、正方形 | `anime-sdxl` | 1024×1024 | 28 | 6.5 |
| シネマティック | 映画のワンシーン風、ドラマチックな光と色調補正、16:9 | `sdxl` | 1344×768 | 32 | 7 |

これらは画質を保証するものではなく、よく使う設定の出発点です。

## 適用したときの動き

- 主役（プロンプト、または「主役・内容」の下書き）の後ろに、プリセットのスタイル語を付け足します。
  別のプリセットに切り替えると、前のプリセットのスタイル語は入れ替わり、重なりません。
- 避けたい要素、幅・高さ、ステップ数、CFG を上書きします。LoRA を選んでいてプリセットに
  LoRA の強さがあるときは、その強さも入れます。
- 推奨モデルが配置済みならそのモデルに切り替えます。未配置のときは選択中のモデルのまま適用し、
  その旨を表示します。
- 適用後は「プリセット『…』の設定」に現在の値が表示されます。表示は欄の値そのものなので、
  欄を変更すると表示も変わり、送信される値と食い違うことはありません。

## プリセットは入力の補助だけ

ジョブとアセットには、実際に送った値（モデル、プロンプト、サイズ、ステップ数、CFG、LoRA）が
記録されます。どのプリセットを選んだかは記録しません。そのため、過去のアセットを再利用すると、
今どのプリセットを選んでいるかに関係なく、そのアセットの値が復元されます。

## 項目と検証ルール

`validateImagePreset()` がすべてのプリセットを検証し、テスト
（`apps/web/src/lib/imagePresets.test.ts`）が `models/manifests/image/` の public_id と突き合わせます。

| 項目 | ルール |
|---|---|
| `id` | 小文字のケバブケース、重複不可 |
| `name` / `intent` / `promptAdditions` | 空でないこと |
| `modelId` | `models/manifests/image/*.json` の `public_id` のいずれか |
| `width` / `height` | 64 の倍数、512〜2048 |
| `steps` | 1〜150 の整数 |
| `guidanceScale` | 0〜30 |
| `loraScale`（任意） | 0〜2 |

スケジューラ（サンプラー）は画面で選べないため、プリセットの項目に含めません。モデルごとの既定を使います。
