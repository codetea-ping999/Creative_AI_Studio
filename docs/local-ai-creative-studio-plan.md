# Local AI Creative Studio 実行プラン

## 目的
「プロンプト作成とパラメータ調整だけで作品制作できるローカル環境」を整備し、
画像・音楽・テキストの生成を一つの制作フローとして扱えるようにする。

## 完成イメージ
- 生成に必要なモデルがローカルに配置済み
- API と UI から、`プロンプト` + `調整値` だけでジョブを実行
- 出力（画像・音声・メタデータ）がプロジェクト単位で保存される
- 失敗時の原因（モデル未配置、VRAM不足、設定ミス）が即時に可視化される

## 段階的ロードマップ

### Phase 1: ローカル基盤の安定化
- モデル配置・依存関係・GPU認識チェックをスクリプト化（既存の setup/check スクリプトを定常運用）
- ヘルスチェック API で「何が足りないか」を返す
- 最低限のプリセット（例: portrait / anime / cinematic）を定義

### Phase 2: プロンプト駆動ワークフロー
- ジョブ入力を `prompt`, `negative_prompt`, `seed`, `steps`, `cfg_scale` 等に統一
- プロジェクトごとの設定テンプレート機能を追加
- 生成結果に「実行時パラメータ」を必ず紐付けて保存

### Phase 3: クリエイティブスタジオ化
- 画像・音楽・テキストを単一プロジェクトのタイムラインで管理
- バリエーション生成（seed差分、LoRA切替、強度スライダー）を UI から実行
- 良い出力をプリセット化して再利用

## 運用ルール（重要）
- **Prompt First**: 機能追加前に「入力文法」を固定する
- **Reproducible**: seed と実行設定を必ず保存する
- **Small Feedback Loop**: 1回の生成は短時間で返し、反復速度を上げる
- **Local-Only Safe**: データ外部送信をデフォルト無効にする

## すぐ着手する ToDo（短期）
1. 既存 API のジョブ入力スキーマを棚卸しし、プロンプト中心に正規化する
2. UI に「テンプレート読み込み + 微調整」の入力セクションを追加する
3. 出力ファイルとパラメータJSONを同じジョブIDで保存する
4. エラー原因を UI と API レスポンスで人間向けに明示する

## 成果判定（Definition of Done）
- 新規ユーザーがセットアップ後 30 分以内に 1 作品出力できる
- 同じ seed/設定で再生成して同等結果を再現できる
- 少なくとも 3 種類の制作テンプレートが利用可能
